# 碰撞箱分析

## 方块方向与碰撞箱关系

在 `BlockRegister.java` 中，`AirshipSlats` 方块的碰撞箱定义如下：

```java
VoxelShape north = box(0, 4, 14, 16, 13, 16);
VoxelShape south = box(0, 4, 0, 16, 13, 2);
VoxelShape west = box(14, 4, 0, 16, 13, 16);
VoxelShape east = box(0, 4, 0, 2, 13, 16);
```

## 碰撞箱参数解释

根据用户的描述：
- **前三个参数**：靠近 (0,0,0) 的碰撞箱顶点坐标
- **后三个参数**：远离 (0,0,0) 的碰撞箱顶点坐标
- **坐标轴方向**：当方块朝向改变时，坐标轴方向保持不变

## 各方向碰撞箱分析

### 1. 北方向 (North)
```java
VoxelShape north = box(0, 4, 14, 16, 13, 16);
```
- X轴：0 → 16（整个方块宽度）
- Y轴：4 → 13（方块中部区域）
- Z轴：14 → 16（靠近方块北部边缘，因为Z轴正方向是北）

### 2. 南方向 (South)
```java
VoxelShape south = box(0, 4, 0, 16, 13, 2);
```
- X轴：0 → 16（整个方块宽度）
- Y轴：4 → 13（方块中部区域）
- Z轴：0 → 2（靠近方块南部边缘，因为Z轴0方向是南）

### 3. 西方向 (West)
```java
VoxelShape west = box(14, 4, 0, 16, 13, 16);
```
- X轴：14 → 16（靠近方块西部边缘，因为X轴正方向是东，所以14-16是西边缘）
- Y轴：4 → 13（方块中部区域）
- Z轴：0 → 16（整个方块长度）

### 4. 东方向 (East)
```java
VoxelShape east = box(0, 4, 0, 2, 13, 16);
```
- X轴：0 → 2（靠近方块东部边缘，X轴0方向是西，所以0-2是东边缘）
- Y轴：4 → 13（方块中部区域）
- Z轴：0 → 16（整个方块长度）

## 实现机制

在 `CustomDirectionalBlock` 类中：
1. 构造函数接收四个方向的碰撞箱并存储在 `shapes` Map中
2. `getShape` 方法根据方块当前朝向返回对应的碰撞箱
3. 当方块朝向改变时，直接使用预定义的对应方向碰撞箱，无需旋转坐标轴

## 结论

碰撞箱定义是正确的，符合用户的理解：
- 每个方向都有独立的碰撞箱定义
- 坐标轴方向在朝向改变时保持不变
- 碰撞箱参数遵循 "前三个靠近原点，后三个远离原点" 的规则

这种实现方式简单直接，确保了方块在不同朝向下都能正确显示碰撞箱。
