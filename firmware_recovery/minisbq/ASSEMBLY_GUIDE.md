# STM32 最小系统板装配指南

本项目没有专用成品 PCB。核心硬件是材料图最左侧的 STM32F103C8T6 最小系统板，外围模块通过杜邦线、排针或洞洞板点对点连接。

## 需要的材料

1. STM32F103C8T6 最小系统板（材料图左侧款式，带 Micro-USB、8 MHz 晶振和 4 针 SWD 口）。
2. 0.96 英寸左右的四针 I²C 128×64 OLED，SSD1306/SH1106 类，地址 `0x3C`。
3. EC11 旋转编码器模块，带 A/CLK、B/DT、SW、VCC、GND 五个接口。
4. ST-Link V2 或兼容 SWD 下载器。
5. 杜邦线或洞洞板、排针、焊锡；建议增加 PA0 输入保护元件。

## 点对点连接

```text
STM32 最小系统板                         OLED
3.3V  --------------------------------> VCC
GND   --------------------------------> GND
PB6   --------------------------------> SCL
PB7   --------------------------------> SDA

STM32 最小系统板                         EC11 模块
3.3V  --------------------------------> + / VCC
GND   --------------------------------> GND
PA8   --------------------------------> CLK / A
PB9   --------------------------------> DT / B
PA12  --------------------------------> SW

STM32 最小系统板                         外部端子
PA0   <-------------------------------- 采集输入（ADC1_IN0）
PA9   --------------------------------> 20 kHz 测试方波输出
GND   --------------------------------> 信号公共地
```

若 EC11 模块插针没有清晰标识，应先用万用表确认公共端和按键端。不同厂家的五针排列可能不同，不能只看模块朝向照抄。

## ST-Link 接线

按信号名连接，不要仅根据 4 针插座从左到右的位置判断：

| ST-Link | 最小系统板 |
|---|---|
| SWDIO | SWDIO / PA13 |
| SWCLK | SWCLK / PA14 |
| GND | GND |
| 3.3V/VREF | 3.3V，仅在确认下载器接口性质及供电方案后连接 |
| NRST（若有） | R/NRST，可选 |

常见粉色 ST-Link V2 克隆的 `3.3V` 脚通常是电源输出，而不是纯电压检测脚。避免让 USB 5V 经板载稳压器与 ST-Link 3.3V 同时反向供电。推荐二选一：

- 调试时由 ST-Link 3.3V 供电，断开最小板 USB；或
- 由最小板 USB 供电，ST-Link 只接 GND、SWDIO、SWCLK（若下载器必须检测 VCC，再确认其接口电路后连接 VREF）。

正常从 Flash 启动时将 BOOT0 设为 0；BOOT1/PB2 也保持 0 即可。

## 原始固件烧录

原始 HEX 已包含基址，可直接使用 ST-Link 工具烧录：

```text
文件：E:\sbqfby\minisbq.hex
Flash 基址：0x08000000
目标：STM32F103C8T6
```

烧录前建议先执行整片擦除，再下载并校验。不要修改或覆盖归档的原始 HEX；需要测试时使用副本。

## 推荐装配顺序

1. 只给最小系统板供电，测量 3.3V 与 GND 之间是否正常且无明显发热。
2. 连接 ST-Link，烧录原始 HEX 并执行校验。
3. 只接 OLED，确认可以点亮并刷新界面。
4. 连接 EC11，验证旋转方向和按压切换。
5. 用示波器或逻辑分析仪检查 PA9，应得到约 20 kHz、约 50% 占空比方波。
6. 初次测试 PA0 时，用 10 kΩ 电位器两端接 3.3V/GND、滑动端接 PA0，避免直接接未知信号源。
7. 确认基本功能后，再焊到洞洞板并增加采集输入保护。

## PA0 输入保护建议

原图没有成品模拟前端，固件也无法提供电气保护。最简单的调试保护可在 PA0 前串联 1–10 kΩ 电阻，并增加到 3.3V/GND 的低电容钳位。真正测量更高电压、交流或负电压时，还需要分压、偏置和过压保护电路。

在模拟前端完成前，PA0 必须保持在 0–3.3V；严禁直接连接市电、负电压或高于 3.3V 的信号。

## 板载引脚位置提示

以材料图中 USB 插座在上、SWD 四针口在下的方向观察：

- PA8、PA9、PA12 位于左侧排针上半部；
- PB6、PB7、PB9 位于左侧排针下半部；
- PA0 位于右侧排针下半部；
- 最终焊接仍以 PCB 丝印为准，焊接前用万用表确认 GND 和 3.3V。
